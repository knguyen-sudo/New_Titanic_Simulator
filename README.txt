# Titanic Survival Simulator | Machine Learning Through Disaster

## Team
- Khue Nguyen

## Description
The Titanic Survival Simulator is a machine learning project that predicts whether a passenger would survive the Titanic disaster. 

Predictions are based on features such as age, passenger class, cabin, port of embarkation, and family size.

## Tech Stack
- Python 3.x
- Jupyter Notebook
- Libraries: pandas, numpy, matplotlib, seaborn, ucimlrepo

## Data Sources
- Kaggle: Titanic - Machine Learning from Disaster  
- https://www.kaggle.com/competitions/titanic/overview

## Dataset
This project uses the Titanic dataset from Kaggle, which includes:
- train.csv – training data with survival labels
- test.csv – test data without survival labels
- gender_submission.csv – example submission file based on gender
- Titanic-dataset.csv – combined dataset used for analysis
