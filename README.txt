Titanic Survival Predictor

## Overview
This project is a data mining analysis of the famous Titanic dataset. It explores passenger data to understand survival patterns and builds predictive models to simulate survival outcomes based on various features like age, class, gender, and fare.

## Dataset
The project uses the Titanic dataset from Kaggle, which includes:
- `train.csv`: Training data with survival labels
- `test.csv`: Test data without survival labels
- `gender_submission.csv`: Sample submission file
- `Titanic-Dataset.csv`: Combined or additional dataset

## Requirements: PLease ensure you have these requirements 
- Python 3.x or the latest Python version
- Libraries: pandas, numpy, matplotlib, seaborn, ucimlrepo
