# Titanic Surival Simulator | Machine Learning through disaster

## Team:
- [Khue Nguyen] 

## Description:
The Titanic Surivor Simulator is a data mining project that focuses on building a prediction model 
to determine the outcome if a person would have surived if they were to board the Titanic.
Prediction will be made depending on the person's age, class, cabins, embarked, family size etc.

## Tech Stack:
This project required the usage of Jupyter Noteook which is a tool tht is used for machine learning.

## Data Sources:
- Kaggle: Titanic - Machine Learning from Disaster
- [Link]: https://www.kaggle.com/competitions/titanic/overview

## Dataset:
This project uses the Titanic dataset from Kaggle, which includes:
    - [train.csv: Titanic training data with the surival label]
    - [test.csv: Titanic test data without the surival label] 
    - [gender_submission: Consist of the genders] 
    - [Titanic-dataset.csv: Titanic combined dataset]

## Installation & Setup:
    - Python 3.x or the latest Python version
    - Libraries: pandas, numpy, matplotlib, seaborn, ucimlrepo
